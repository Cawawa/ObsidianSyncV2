Modalità di trasmissione [[Ereditarietà monogenica|monogenica]] legata ai cromosomi sessuali, in particolare al cromosoma X. La manifestazione clinica si osserva soprattutto in ==soggetti maschili== perché emizigoti.

La femmina può essere portatrice sana, asintomatica, secondo il fenomeno dell' [[Inattivazione del cromosoma X]] (*lyonizzazione*).

- Padre affetto trasmette a tutte le figlie femmine

| \        | <span style="color:rgb(192, 0, 0)">$X^{mut}$</span>            | $Y$          |
| -------- | -------------------------------------------------------------- | ------------ |
| $X^{wt}$ | <span style="color:rgb(255, 255, 0)">$X^{mut}$/$X^{wt}$</span> | $X^{wt}$/$Y$ |
| $X^{wt}$ | <span style="color:rgb(255, 255, 0)">$X^{mut}$/$X^{wt}$</span> | $X^{wt}$/$Y$ |

- Madre affetta o portatrice eterozigote trasmette al 50% delle figlie femmine e al 50% dei figli maschi

| \                                                     | $X^{wt}$                                                       | Y                                                       |
| ----------------------------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------- |
| $X^{wt}$                                              | $X^{wt}$/$X^{wt}$                                              | $X^{wt}$/$Y$                                            |
| <span style="color:rgb(255, 255, 0)">$X^{mut}$</span> | <span style="color:rgb(255, 255, 0)">$X^{mut}$/$X^{wt}$</span> | <span style="color:rgb(192, 0, 0)">$X^{mut}$/$Y$</span> |

Esempio: [[Daltonismo]], [[Distrofia muscolare di Duchenne]]
