Modalità di trasmissione [[Ereditarietà monogenica|monogenica]] legata al cromosoma X. Lo schema è simile a quello delle [[Trasmissione delle patologie tipo autosomico-dominante|patologie autosomiche dominanti]], con la differenza che l'individuo maschio affetto non trasmette l'allele ai figli maschi,

| \        | <span style="color:rgb(192, 0, 0)">$X^{mut}$</span>          | $Y$          |
| -------- | ------------------------------------------------------------ | ------------ |
| $X^{wt}$ | <span style="color:rgb(192, 0, 0)">$X^{mut}$/$X^{wt}$</span> | $X^{wt}$/$Y$ |
| $X^{wt}$ | <span style="color:rgb(192, 0, 0)">$X^{mut}$/$X^{wt}$</span> | $X^{wt}$/$Y$ |

| \                                                   | $X^{wt}$                                                     | Y                                                       |
| --------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| $X^{wt}$                                            | $X^{wt}$/$X^{wt}$                                            | $X^{wt}$/$Y$                                            |
| <span style="color:rgb(192, 0, 0)">$X^{mut}$</span> | <span style="color:rgb(192, 0, 0)">$X^{mut}$/$X^{wt}$</span> | <span style="color:rgb(192, 0, 0)">$X^{mut}$/$Y$</span> |

Le donne manifestano la patologia in modo più leggero per i fenomeni di [[Inattivazione del cromosoma X]].

Esempi: [[Incontinentia pigmenti]], [[Sindrome di Rett]]
