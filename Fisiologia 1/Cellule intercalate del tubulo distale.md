Cellule del [[Tubulo Distale]] nel rene. Duplice funzione, in base alla necessità (*c'è un meccanismo di plasticità celluare*).
- Eliminare l'eccesso di protoni
- Rigenerare $HCO_{3}^{-}$ usato per tamponare acidi/riassorbire $H^+$

| Tipo cellula | Secrezione (urina) | Riassorbimento (sangue) | Funzione          |
| ------------ | ------------------ | ----------------------- | ----------------- |
| Tipo A       | H⁺                 | HCO₃⁻                   | Contro l'acidosi  |
| Tipo B       | HCO₃⁻              | H⁺                      | Contro l'alcalosi |

| Tipo cellula | Pompe $H^+$  | Scambiatore $Cl-/HCO_{3}^{-}$ |
| ------------ | ------------ | ----------------------------- |
| Tipo A       | ==Apicale==  | Basolaterale                  |
| Tipo B       | Basolaterale | ==Apicale==                   |

>A "Acidificanti" e B "Bicarbonato"

Idrogenioni nel lume $\to$ si forma ione bicarbonato $\to$ recupero CO2 $\to$ abbassamento acidosi

Esistono poi cellule nonA-nonB, dalla funzione non ancora chiara, che esprimono entrambi i sistemi all'apice.
